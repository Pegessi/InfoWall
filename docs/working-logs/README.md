# Working Logs

Focused, dated logs for non-trivial development work. One file per topic, named
`YYYY-MM-DD-topic.md`.

Each log should cover:

- **What changed** — the concrete scope of the work.
- **Why** — the motivation or problem being solved.
- **Key decisions** — design choices and the alternatives considered.
- **Pitfalls** — anything surprising worth warning the next person about.

Keep the root agent files (`AGENTS.md` / `CLAUDE.md`) short; when a lesson here
becomes stable, add a one-line navigation cue to those files and leave the
detail in the log.
